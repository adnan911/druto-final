FROM TEMPLATE TO YOUR STORE

Make yourself at home.

A considered storefront, your own order database, and a clear path to Druto checkout. Follow the full README included in your download for commands and operational requirements.

01. Make it yours

Install Node.js 22.12+ and run these commands in the extracted starter. Change your brand in public/index.html, your colors in public/tokens.css, and your server-owned products in src/catalog.js.

npm install
npm run dev

02. Create a home for orders

Create a separate Cloudflare D1 database for this store. Copy its ID into the starter’s wrangler.jsonc. Do not use the gateway’s payment database.

npx wrangler login
npx wrangler d1 create my-druto-store
npm run db:local
npm run db:remote

03. Connect your seller

Open the Druto dashboard ↗, verify your receiving wallet, and create your seller API key and webhook endpoint. Set the public seller IDs, receiving address and store URL in the configuration. Ask the Druto operator to enable your exact webhook origin.

Webhook URL:
https://YOUR-STORE.YOUR-SUBDOMAIN.workers.dev/api/webhooks/druto

npx wrangler secret put DRUTO_API_KEY
npx wrangler secret put DRUTO_WEBHOOK_SECRET

Enter secrets only in Wrangler’s private prompt. Never paste them into browser code or the configuration’s public variables. If the Worker does not exist yet, deploy once without secrets; payments remain disabled until setup is complete.

04. Publish your Testnet store

npm run check
npm run deploy

Complete one small Arc Testnet order in the same browser session. Confirm its signed webhook reaches your store and its status becomes paid. Retry the webhook and confirm it does not create a second fulfillment job.

05. Add what makes it yours

Demo products are not real downloads. Connect an idempotent delivery worker to the fulfillment queue and add customer account recovery before using this as a real store. Payment confirmation and delivery are separate. Review security, refunds, monitoring and country requirements before any real-money launch.

Testnet only. This template does not enable mainnet payments or establish regulatory permission to accept payments.
